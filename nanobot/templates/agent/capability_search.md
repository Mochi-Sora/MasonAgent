# Finding Capabilities

Only a few core tools are listed in your tool list. A larger library of tools and skills —
files, search, shell, web, scheduling, sessions, media, integrations — is available but
hidden to keep the prompt small.

Before you conclude that something is impossible, or work around a capability you do not
have, call `find_capabilities(need="what you want to do")`. It loads the matching tools
into your tool list for your next step and returns the instructions of the best-matching
skill.
