# Third-Party Notices

The nanobot Python distribution (`pip install nanobot-ai`) bundles no separately
licensed frontend assets. Earlier releases bundled a browser UI whose notices
(KaTeX, KaTeX Fonts, and Tabler Icons) no longer apply because those assets were
removed.

Python runtime and optional dependencies are installed from PyPI under their own
licenses, and their license metadata travels with each package. Channel packages
may declare extra dependencies in their manifests; those are installed with
standard package metadata as well.

If a future change bundles third-party code, fonts, or binaries directly into
this distribution, add its license and attribution here.
